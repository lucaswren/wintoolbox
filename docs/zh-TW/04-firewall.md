# 04 · 防火牆

一鍵開關設定檔案、禁 ping、攔高危入站連接埠，以及按連接埠放行/刪除規則。

## 第一步：下載

https://github.com/lucaswren/wintoolbox/releases/latest

攔截點 **保留 / 保持**。詳：[00 · 下載](./00-download.md)

![下載攔截示意（模擬）](../images/00-download.png)

## 介面標注

![防火牆（真實介面）](../images/04-firewall.png)

| # | 按鈕 | 說明 |
|---|------|------|
| ① | **全部開啟** | 域 / 專用 / 公用設定檔案全部啟用（旁有「全部關閉」） |
| ② | **放行** | 為填寫的 TCP 連接埠添加入站放行（規則名前綴 WinToolBox） |
| ③ | **封鎖 ICMP Echo** | 阻止 ICMPv4/v6 Echo（可 **恢復 ping**） |
| ④ | **攔高危入站連接埠** | 攔 135 / 139 / 445 / 5985 / 5986（**不含 3389**） |

同頁還可 **按連接埠刪除**、**移除高危攔截**，以及管理「已創建規則」列表。

## 步驟

1. **防火牆** → 確認設定檔案為開啟（必要時 ①）
2. 運維需要時用 ② 放行業務連接埠
3. 加固：③ 禁 ping → ④ 攔高危連接埠

依賴檔案共享 / WinRM 時慎用 ④。雲主機還需在安全組同步策略。
