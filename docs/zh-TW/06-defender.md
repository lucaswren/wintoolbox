# 06 · 防病毒

一鍵關閉或恢復 Windows Defender **即時防護**。

## 第一步：下載

https://github.com/lucaswren/wintoolbox/releases/latest

攔截點 **保留 / 保持**。詳：[00 · 下載](./00-download.md)

![下載攔截示意（模擬）](../images/00-download.png)

## 介面標注

![防病毒（真實介面）](../images/06-defender.png)

| # | 按鈕 | 說明 |
|---|------|------|
| ① | **關閉即時防護** | 臨時關閉 Defender 即時監控（有風險） |
| ② | **恢復即時防護** | 重新開啟即時監控 |

## 注意

- 若開啟 **篡改防護**，關閉可能失敗，需先在 Windows 安全中心處理
- 僅在明確需要的運維窗口關閉，用完立即 **恢復即時防護**
- 狀態顯示「未知」時先點 **刷新**
