# 全功能、操作逻辑与界面审查 · 2026-10-12

## 高危端口操作慢且没有反馈的原因

旧逻辑逐个处理五个端口，每个端口都启动一次 PowerShell，包含写入和复查，失败后又执行 netsh 删除、创建和更多查询。移除操作在 PowerShell 批量删除之后，无条件再次调用五次 netsh。超时限制仅作用于单条命令，没有整个工作流的总预算。本机只读防火墙查询约耗时 2 秒；这不是实际拦截操作的性能对比。

前端只禁用按钮，没有执行阶段或耗时提示，且在最后的状态刷新前就弹出成功消息。日志折叠、短暂弹窗消失，让用户难以判断结果。刷新包装函数还丢弃了返回的快照，调用方无法检查未知状态。

## 已完成修复

- 五个端口使用一次 PowerShell 批量写入，成功路径不再调用 netsh 修复。写入、备用路径和复查共享 60 秒的命令工作流预算，批量命令限时 30 秒。系统服务和调度仍会影响耗时，不显示虚构进度百分比。
- 拦截复查检查入站方向、TCP、启用状态、阻止动作、全部配置文件及目标端口；缺失、错误或无法读取的结果保持未知。移除必须确认五个规则全部不存在，不能把“规则已禁用”当成“删除成功”。
- 已启用的远程桌面端口若位于预设清单，或无法读取远程桌面配置，会中止拦截。只排除 3389 无法保护自定义端口。
- 在滚动内容上方显示持续状态栏：正在执行、正在复查、完成、需要复查、未完成，包含耗时。切换页面仍可见；结果保留到手动关闭或下一次操作。失败后也复查，以呈现已发生的部分修改。
- 最后复查完成后才提示完成；未知状态或复查失败保留警告。Windows 已接受的操作不会自动撤销。阶段提示不代表逐端口实时进度。
- 防火墙页面逐个显示五个端口的规则状态，并说明本地规则配置不等于实际网络过滤效果。
- 远程桌面切换不再预先改写界面，账户锁定取消重复刷新；账户启用/禁用增加状态回读。
- Windows Update 关闭操作不能在状态未知时确认成功；界面描述检测到的配置，不再声称服务运行中。NTP 测试必须存在有效时间偏移样本；即使命令正常退出，输出含 Windows 错误码仍判失败。

## 十个模块逐项结论

| 模块 | 审查内容与效果边界 |
|---|---|
| 本机概览 | 快速/详细采集、缓存、激活标签、未知字段、GiB 及可用/总容量。硬件超时不伪造信息。 |
| 本地账户 | 密码验证、当前用户保护、账户和管理员权限回读、Guest/自动登录、密码复杂度和锁定策略。密码不能回读；API 成功不等于已完成实际登录测试。域策略可覆盖本地策略。 |
| 远程桌面 | 端口验证、规则同步和回滚、NLA 回读、服务重启失败、历史清理。配置端口和启用策略不代表实际监听或外部可连接。内置规则组同步仍为异步。 |
| 防火墙 | 配置文件、放行、ICMP Echo、五端口预设、删除和未知状态。本地规则不证明端到端拦截；关闭配置文件、域策略、地址限制、云安全组和路由均影响效果。 |
| 安全加固 | SMB 服务端设置、可选组件、WinRM 服务和规则、匿名枚举。组件可能需重启，不等于完整安全基线；服务操作仍可能较慢。 |
| Microsoft Defender | 偏好/策略写入、备份、防篡改错误和状态回读。启用是强制开启，不是恢复过去的关闭偏好；不会绕过防篡改保护。 |
| 时间同步 | 时区、NTP 源、服务重启、重新同步和样本。一次有效响应不代表长期稳定；同步命令不独立测量时钟精度。 |
| 电源 | 延迟范围、权限、强制关机/重启确认、取消。计划成功不等于已经关机；锁屏会立即遮挡界面。 |
| Windows Update | 备份有效性、策略/服务/任务恢复、损坏备份拒绝、聚合状态。还原后可能仍关闭，因为原配置如此；系统修复和域策略可再改写设置。 |
| 软件更新 | 发布资源选择、校验、取消、暂存权限、替换及回滚日志。已有独立下载进度界面；SHA256 不验证发布者身份，进程未退出不代表界面完整就绪。EXE 尚未签名。 |

## 界面、说明书与验证

三种语言检查十个页面，覆盖 960×600、默认 1280×800 无溢出、表单草稿、语言保存和确认框。模拟浏览器故意暂停写入与复查，并验证完成、失败、未知警告。测试不执行本机管理写入。

状态栏位于主滚动区域之外，长页面底部操作也能看到反馈；长说明换行，超长结果在有限区域内滚动。日志仍仅保存在当前会话，不跨重启保存。说明书已补充操作阶段、部分修改、逐端口结果及配置状态的含义。既有标注截图为历史示意，不包含新状态栏。

验证：15 项前端测试、lint/类型/格式检查，Go 测试/vet、桥接一致性、PowerShell 写入脚本只解析语法、三语言浏览器测试和 Windows 生产构建。本机没有执行端口拦截、账户修改、防护/更新变更或电源操作。

## 仍需隔离环境验收

在一次性 Windows 虚拟机验证真实写入、服务停用、域管理、权限不足、超时、部分生效及实际耗时；从另一台机器测试入站连接。包含自定义远程桌面端口冲突、全部防火墙配置关闭、重复或限缩规则、禁用规则删除、UAC/WebView2、不同 DPI 和多显示器、SMB 重启、系统更新任务差异。

60 秒预算只用于高危端口命令工作流，不代表所有操作都有同样时限。SMB 组件、更新服务/任务和策略传播仍可能较慢；并非所有原生调用或系统提供程序都能取消。超时不等于没有修改，应刷新并检查部分状态。
