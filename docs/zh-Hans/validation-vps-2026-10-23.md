## 软件更新

- 下载测试改用注入 HTTP 传输边界，不依赖本地网络、代理或防火墙；验证真实下载流程中状态读取不阻塞、取消能停止读取并清理部分文件。
- 更新器测试改在工作区临时目录执行实际 PowerShell 脚本，避开受限 Windows 环境对 Go 系统临时目录中文件替换的限制。
- 断言必须经过注入的启动失败并恢复原文件；不能把“根本没有替换成功”误当作回滚成功。
- 补充传输失败、损坏包校验与清理测试。没有更换生产下载协议或降低 SHA256 验证要求。

## RDP 异常路径

- 白名单：IPv4/IPv6 混合、地址规范化、宽泛规则、受管策略、本地规则合并关闭、已有白名单再次修改与恢复。
- 回滚：任务注册失败、延迟激活任务创建失败、部分写入、截止时间、原监听恢复失败后重试、规则并发修改冲突。
- 原始访问尚未恢复时保留事务临时规则；避免恢复失败后又删除最后的可用通道。
- 模拟磁盘写入失败：即使无法保存“恢复中”状态或写日志，也先尝试恢复原网络配置；最终状态无法落盘时保留任务重试。
- 确认：旧记录、变更前时间、未来时间、错误会话、控制台点击、过期事务均拒绝。增加日志记录序号基线，旧时间戳不能单独成为新连接证据。
- 回滚任务丢失、禁用、执行身份或动作改变，以及保护规则失效、来源扩大或防火墙失效时拒绝保留。
- 使用 Windows 原生命名互斥锁序列化不同程序实例/会话的网络检查与写入；原有按进程互斥不能覆盖该场景。持有原生互斥锁时固定 Go 线程。
- 原生并发测试覆盖已存在的互斥锁句柄；正确处理 Windows 同时返回有效句柄与 `ERROR_ALREADY_EXISTS` 的情况。
- UI 确认对话框绑定最初事务 ID，后台轮询切换事务后不能把旧对话框确认用于新事务。

## 验证边界

自动化事务测试使用模拟的注册表、防火墙、服务、事件和计划任务，不修改真实主机的网络配置。它们验证真实脚本的控制流程，但不能替代 Windows Server 2016/2019/2022/2025 的实际 RDP 断连重连、SYSTEM 任务运行、系统重启和云安全组验收。

未使用真实 VPS 执行危险变更，也未将“代码测试通过”等同于“所有服务器版本已认证”。生产操作仍应保留服务商控制台入口；云平台故障、凭据失效、系统损坏或任务服务失效可能需要人工恢复。

## Windows 11 问题修复补充（2026-10-27）

- 用户反馈修改 RDP 端口被 `NETDIS-UPnPHost-In-TCP-Teredo` 拦截。只读检查本机同名规则，确认其条件为 `Program=System`、`Service=Any`、`LocalPort=Any`；本机该规则未启用。原候选筛选错误地将 `System` 包含在 TermService 服务宿主程序范围内，用户环境启用此规则时会误报宽泛 RDP 放行。
- 修复按程序条件排除 `System` 规则，不根据规则名称豁免。模拟启用该规则后，改端口、白名单和重新连接确认均通过，原 Teredo 规则不变；`Any` 和 `svchost.exe` 的真实宽泛规则继续拒绝。原有回滚和重连异常场景继续验证。
- 加固状态原先顺序调用两次服务命令、两次防火墙 PowerShell 查询，失败时再调用 netsh，可能超过界面 15 秒等待期限。改为原生只读服务查询、一次有效防火墙规则批量查询，与 SMB 查询并行；共同 12 秒预算包含命令排队，接入页面取消上下文。服务查询仅请求读取配置和状态权限。
- 查询超时、访问拒绝或不完整 JSON 标记为未知；规则确实不存在时返回未拦截。验证 TCP/入站/阻止/启用/准确端口，避免将 UDP、出站规则或 59850 误当作 5985；慢查询不会丢弃已读取的匿名限制和 SMB 注册表回退结果。
- 本机 Windows 11 只读运行修复后的完整加固状态采集，首次约 2.94 秒，复验约 2.81 秒，三类状态均已读出；页面实际调用的 `GetModuleStatus("harden", false)` 约 2.52 秒，无未知状态、警告或错误。另补测用户的 11139 → 47821 端口变更与重连确认模拟场景。没有更改真实 RDP 端口、防火墙或服务配置，也未执行真实远程断连重连；Server/VPS 实机验收边界保持不变。

防火墙程序条件参考：[Microsoft Get-NetFirewallApplicationFilter](https://learn.microsoft.com/powershell/module/netsecurity/get-netfirewallapplicationfilter)。
