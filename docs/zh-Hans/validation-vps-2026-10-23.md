## 各页面小窗口排版复查

- 覆盖 11 个页面、账户 2 个页签、远程桌面 4 个页签；简体中文、英文、繁体中文；800×500、960×600、1120×720、1320×840；活动日志展开与收起，共 360 组普通布局检查。
- 另验证 6 组“失败提示 + RDP 待确认 + 展开日志”叠加场景，包含最小窗口下的恢复按钮。
- 发现并修复：800×500 下同时展开日志和显示保护提示时，英文界面底部超出窗口、主内容区被挤压；中文界面内容区也过窄。日志展开高度随窗口缩至 80–180px，RDP 提示最高占窗口高度的 30% 且不超过 220px，内容可独立滚动。
- 修复后 366 组检查通过：页面不产生额外横向溢出，表格横向滚动区域保留；按钮、输入框、复选框及全局恢复/日志操作在滚动到位后可完整显示并命中；顶部、底部不覆盖主内容，也不会把整个窗口滚出可视区。
- 加载动画消失后才检查遮挡，避免将正常的读取遮罩当成排版缺陷。全部既有菜单、控件和功能保留，按钮与表格继续使用默认组件尺寸。
- 前端 20 项测试、代码检查、生产构建通过；原有白名单、确认门槛、回滚、客户端清理、系统日志和导出模拟验收继续通过。

完整复验：设置 `WINTOOLBOX_UI_DIST=1`、`WINTOOLBOX_LAYOUT_AUDIT=1` 后运行 `python scripts/ui-smoke.py`；结果写入 `artifacts/ui/layout-audit.json`。这些是模拟 Wails 后端的浏览器排版验证，不替代 Windows Server/VPS 实机验收。

## 软件更新

- 下载测试改用注入 HTTP 传输边界，不依赖本地网络、代理或防火墙；验证真实下载流程中状态读取不阻塞、取消能停止读取并清理部分文件。
- 更新器测试改在工作区临时目录执行实际 PowerShell 脚本，避开受限 Windows 环境对 Go 系统临时目录中文件替换的限制。
- 断言必须经过注入的启动失败并恢复原文件；不能把“根本没有替换成功”误当作回滚成功。
- 补充传输失败、损坏包校验与清理测试。没有更换生产下载协议或降低 SHA256 验证要求。

## RDP 异常路径

- 白名单：IPv4/IPv6 混合、地址规范化、宽泛规则、受管策略、本地规则合并关闭、已有白名单再次修改与恢复。
- 回滚：任务注册失败、延迟激活任务创建失败、部分写入、截止时间、原监听恢复失败后重试、规则并发修改冲突。
- 原始访问尚未恢复时保留事务临时规则；避免恢复失败后又删除最后的可用通道。
- 模拟磁盘写入失败：即使无法保存“恢复中”状态或写日志，也先尝试恢复原网络配置；最终状态无法落盘时保留任务重试。
- 确认：旧记录、变更前时间、未来时间、错误会话、控制台点击、过期事务均拒绝。增加日志记录序号基线，旧时间戳不能单独成为新连接证据。
- 回滚任务丢失、禁用、执行身份或动作改变，以及保护规则失效、来源扩大或防火墙失效时拒绝保留。
- 使用 Windows 原生命名互斥锁序列化不同程序实例/会话的网络检查与写入；原有按进程互斥不能覆盖该场景。持有原生互斥锁时固定 Go 线程。
- 原生并发测试覆盖已存在的互斥锁句柄；正确处理 Windows 同时返回有效句柄与 `ERROR_ALREADY_EXISTS` 的情况。
- UI 确认对话框绑定最初事务 ID，后台轮询切换事务后不能把旧对话框确认用于新事务。

## 日志与 UI

系统日志分类同时匹配来源和事件 ID；区分异常记录与根因，提供原文、XML、结构化字段、停止代码、时间关联和 JSON 导出。覆盖空结果、截断、禁用、权限错误及消息资源问题的处理，并完成本机 System 日志只读采集校验。

组件尺寸在本轮精简中恢复为 Element Plus 默认值；压缩折叠活动日志的占用，按钮集中排列；RDP 阶段使用可理解的文字。窗口按工作区/DPI 裁切，切页回到顶部。浏览器模拟验收覆盖 11 个页面、960×600 / 1120×720 / 1320×840、RDP 确认门槛、恢复提示、日志搜索、详情抽屉、导出和读取失败保留旧结果。

## 验证边界

自动化事务测试使用模拟的注册表、防火墙、服务、事件和计划任务，不修改真实主机的网络配置。它们验证真实脚本的控制流程，但不能替代 Windows Server 2016/2019/2022/2025 的实际 RDP 断连重连、SYSTEM 任务运行、系统重启和云安全组验收。

未使用真实 VPS 执行危险变更，也未将“代码测试通过”等同于“所有服务器版本已认证”。生产操作仍应保留服务商控制台入口；云平台故障、凭据失效、系统损坏或任务服务失效可能需要人工恢复。
