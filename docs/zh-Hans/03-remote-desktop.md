# 03 · 远程桌面

管理 RDP 连接设置、来源 IP 白名单和服务器登录记录。

## 界面标注

![远程桌面（真实界面）](../images/03-remote-desktop.png)

| # | 选项 | 说明 |
|---|------|------|
| ① | **端口** | 保护流程接受 1024–65535；改端口不能替代白名单和强认证 |
| ② | **保存端口** | 保存原配置、建立独立回滚任务、添加受限 TCP/UDP 规则；约十秒后重启 RDP 服务 |
| ③ | **开启 / 关闭** | 开关远程桌面服务（图示为已开启时的「关闭」） |
| ④ | **强制 NLA** | 认证前拒绝连接；极旧客户端可能连不上 |

页面按**连接设置**、**访问限制**、**登录记录**、**客户端记录**排列。客户端记录保留历史主机、用户名提示、TERMSRV 凭据、相关文件与位图缓存的查看、搜索、按类型筛选、单条删除、当前类型清理和全部清理；打开该页签时读取。清理不更改 RDP 服务或端口。旧截图仅供位置参考。

## 步骤

1. **远程桌面** → 填写端口（①）→ **保存端口**（②）
2. 未开启则点 **开启**（③）→ **强制 NLA**（④）
3. 客户端使用 `IP:新端口`；云主机请同步安全组
4. 五分钟内重新连接，点击顶部 **重新连接成功，保留配置**；未确认则自动恢复

## VPS 防失联保护

端口、NLA、来源白名单和开启全部防火墙使用五分钟保护事务。先保存配置并注册 SYSTEM 计划任务，再修改系统；注册任务失败时不修改连接配置。回滚不依赖程序窗口，关掉工具后仍生效；系统启动时检查超时事务，恢复失败时每分钟重试并保留错误状态。

保留配置必须检测到变更后当前会话的 RDP 登录/重新连接事件，并确认 TermService 真实监听。原有连接仍能操作界面不代表新连接正常，不能据此确认。关闭 RDP、关闭全部防火墙、删除普通放行规则等操作仅允许已识别的本地控制台执行；状态未知时拒绝操作。

确认还会检查变更前的日志记录序号基线、事件时间、回滚任务身份/动作及当前有效规则。旧事件、未来时间、错误会话、任务被修改、来源限制失效或已超时都会拒绝保留。恢复失败时保留临时规则与任务；即使状态文件或日志暂时不能写入，也会先尝试恢复原连接配置。详见[本次异常场景复查](validation-vps-2026-10-23.md)。

**先保留服务商的 VNC/串口/控制台入口。** 回滚只能恢复本机保存的设置，无法恢复云安全组、NAT、外部网关、已失效的凭据、系统故障或不可用的任务计划服务。TermService 在部分系统配置下无法正常重启，可能需要从控制台重启系统。

## 来源 IP 白名单

在 **访问限制** 中，每行填写一个 IPv4、IPv6 或 CIDR，最多 64 项。支持逗号和分号分隔；拒绝 Any、域名、全网 CIDR 和 IPv6 区域标识。空列表不表示解除限制。VPN、RD Gateway 和动态公网出口可能改变服务器看到的来源地址，必须使用实际管理来源。

应用时检查有效策略中的已有 RDP 放行规则，并收紧其来源范围，同时新增限定 TermService 的 TCP/UDP 放行规则。遇到组策略放行规则、无关服务共用的宽泛端口规则或不明确的配置时拒绝修改，避免留下其他开放入口。所有防火墙配置文件必须明确启用、默认入站阻止，并允许合并本地规则；默认动作未明确解析为 Block 时也会拒绝，不推测系统默认值。

修改端口保留现有来源限制，不会自动改成对任意来源开放。已确认白名单后，工具会阻止可能绕过它的普通网络配置入口；需要调整来源时继续使用受保护白名单流程。不会自动清理历史放行规则或第三方策略。

## 连接检查与事件

默认只显示本机监听状态和白名单输入。规则列表、原始检查输出与提示位于 **诊断详情**，按需展开；日志读取后再显示表格，读取失败保留上次结果并明确提示。

- 真实监听检查同时匹配配置端口和 TermService 的进程 ID，不只读取注册表。
- 规则列表读取 ActiveStore，展示可能匹配端口的允许/阻止规则、协议、来源、策略来源和配置文件；其他过滤条件仍需结合实际连接验证。
- 本机检查不验证公网连通、云安全组和 NAT，也不能证明 UDP 链路正常。
- **登录记录** → **读取记录** 可选最近 1、7、30、90 天及 100、300、1000 条上限，读取 LSM、RCM 与 Security 通道，不修改审计策略。某个通道无权限或未启用时保留其他通道结果，并提示日志可能不完整。
- 根据通道、来源和 ID 分类；1149 只表示认证，不等于完整桌面登录。Security 类型 10 归为远程交互式登录，类型 3 失败单独标记“网络认证失败（未确认 RDP）”；普通网络登录、本地会话和来源未知会话不计入已确认远程登录记录。
- 默认显示简短统计和时间、事件、账户、来源地址等关键记录。**筛选与范围** 默认收起，展开后可设置时间、条数、分类及搜索账户、IP 或状态码；有筛选条件时按钮显示数量，收起后也能识别当前正在筛选。失败原因、状态码和通道等信息通过 **查看详情** 查看。
- **登录分析与来源汇总** 默认收起，按 IP 汇总，五分钟内同一来源至少五条失败时给出排查线索；事件条数不等于登录次数或攻击次数，NAT、VPN 和凭据配置错误也会影响判断。采集时间与完整说明位于 **日志说明**，读取失败或不完整时仍保留简短提示。
- **查看详情** 显示通道、记录编号、会话及失败原因，原文、结构化字段和 XML 分别点击展开；**导出诊断报告** 保存整次读取结果，不受当前筛选影响。单条消息、XML 与字段有长度限制，截断时会提示。
- **清空结果** 只清除当前结果、统计、详情、搜索与错误提示，不清除 Windows 原始日志；重新读取仍可显示历史记录。读取期间不能清空，避免异步结果重新填回。

分类参考：[Microsoft 4624 登录类型](https://learn.microsoft.com/en-us/windows/security/threat-protection/auditing/event-4624)和[4625 失败状态](https://learn.microsoft.com/en-us/windows/security/threat-protection/auditing/event-4625)。

## 支持边界与控制台恢复

本阶段面向 Windows Server 2016/2019/2022/2025 Desktop Experience、管理员交互会话、Windows PowerShell 5.1、NetSecurity 和任务计划服务。域成员机器遇到受管 RDP 策略时拒绝覆盖；域控制器拒绝保护变更。Server Core、Session 0 和无法识别的会话不属于可操作范围。自动化测试不能替代各版本 VPS 实机验收。

持久文件位于系统 Program Files 下的 `WinToolBox-RdpSafety`，仅管理员和 SYSTEM 可访问。`pending.xml` 保存当前事务，`whitelist.xml` 保存已确认白名单；`recovery.log` 记录恢复结果。请勿在等待确认时移动或删除目录、脚本、状态文件或任务。

无法通过 RDP 返回时，先等待超时恢复；仍失败则进入 VPS 控制台。可重新打开工具使用顶部 **立即恢复原配置**，或在管理员 PowerShell 手动触发已有恢复任务：

```powershell
Start-ScheduledTask -TaskName 'WinToolBox-RdpSafety-Recover'
```

该任务仅在截止时间之后恢复。发生并发管理员修改时，恢复会保留冲突并提示人工处理，避免覆盖他人的设置；查阅 `recovery.log` 和原始状态，再决定是否从控制台重启系统。不要删除待恢复状态来绕过保护。
