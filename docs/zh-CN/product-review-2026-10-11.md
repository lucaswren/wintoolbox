# 软件审查 · 2026-10-11

检查范围：Wails 窗口、十个功能页面、多语言、账户/RDP/防火墙/加固操作、状态采集、原生启动、自更新暂存、构建脚本和仓库元数据。

默认窗口调整为 1280×800，最小为 960×600。概览双栏、导航紧凑，三种语言的默认概览和侧栏无溢出。小窗口、较长设备清单与列表保留必要滚动。统一显示名称及新构建文件名为 WinToolBox；既有防火墙规则标识、更新缓存和语言设置保持兼容。

已支持英语、繁体中文、简体中文，首次启动识别 Windows 显示语言，不支持的语言回退英语，手动选择持久保存。程序没有独立安装器，直接运行 EXE；缺少 WebView2 时显示对应语言的安装提示。文档英语为主，并提供中文版本，既有截图为历史简体中文示意。

修正容量单位为 GiB，卷数值为可用/总量，防病毒模块明确为 Microsoft Defender。NLA 要求先验证身份再建立会话；密码复杂度由 Windows 策略定义，影响后续密码修改。加固功能提供单项设置，不代表完整安全评估。更新状态改为是否发现更高版本。

资源锁和操作后刷新用于避免相关操作重叠并呈现部分失败。自更新校验 SHA256、重新检查暂存文件、限制暂存目录访问并保留替换/回滚日志。校验和与发布资源处于相同信任边界，不能替代发布者身份验证；当前 EXE 缺少 Authenticode 签名，建议下次发行优先补充签名。

远程桌面和防火墙状态仅表示本地配置。云安全组、域策略、Defender 防篡改和重启条件需要单独确认。

验证通过：前端 lint/类型检查、11 项测试、格式检查；Go 测试/vet；桥接一致性；Windows 生产构建；三种语言十个页面的模拟浏览器测试、960×600 布局、切换/表单草稿/确认框/偏好保存以及 1280×800 无溢出断言。浏览器测试使用模拟数据，不执行管理写入。原生 UAC、全新系统 WebView2 安装、多显示器/DPI 和破坏性操作仍需隔离 Windows 虚拟机验收。
