# 02 · 帳戶管理

停用來賓與自動登錄、加強密碼/鎖定策略，以及修改本地使用者密碼與權限。

## 安全策略

![本地帳戶策略](../images/zh-Hant/02-local-account.png)

| # | 按鈕 | 說明 |
|---|------|------|
| ① | **停用來賓帳戶** | 關閉 Guest，降低未授權入口 |
| ② | **關閉自動登錄** | 關 AutoAdminLogon，並清除 DefaultPassword |
| ③ | **應用密碼策略** | 設置最短長度，並開啟復雜度 |
| ④ | **一鍵開啟鎖定** | 預設約 10 次失敗 / 鎖定 30 分鐘（可自定義） |

也可在同頁填寫閾值後點 **應用自定義策略**。

按 **一鍵關閉鎖定** 會將失敗次數閾值設為 0，並解鎖目前已鎖定的本機帳戶。按 **一鍵開啟鎖定** 會套用 10 次失敗、鎖定 30 分鐘、30 分鐘重設視窗。自訂時可分別填寫這三個數值。

## 修改密碼與權限

開啟 **使用者管理**，找到 **帳戶操作**。

![修改密碼](../images/zh-Hant/02-local-account-password.png)

| # | 選項 | 說明 |
|---|------|------|
| ① | **使用者** | 選擇本地帳戶 |
| ② | **新密碼** | 輸入新密碼 |
| ③ | **確認密碼** | 與 ② 一致 |
| ④ | **修改密碼** | 確認後生效 |
| ⑤ | **設為系統管理員** | 將所選使用者加入系統管理員組（旁有啟用/停用、取消系統管理員） |

## 建議步驟

1. 系統管理員打開 WinToolBox → **帳戶管理**
2. ①②③④ 按需加固
3. 選使用者 → 填兩次密碼 → **修改密碼**
4. 用新密碼登錄驗證一次

密碼建議長度 ≥ 12（伺服器 ≥ 14），含大小寫、數字與符號。本頁只管**本地帳戶**（域帳戶受域策略約束）。

## 修改使用者名稱

在 **使用者管理 → 帳戶操作** 中選擇本機帳戶，填寫 **新使用者名稱**，按 **修改使用者名稱** 並確認。請先關閉自動登入並刷新。新名稱最多 20 個字元，須避開現有帳戶或群組名稱。

帳戶的 SID、密碼、權限和使用者資料夾路徑會保留。如果修改目前登入的帳戶，請登出後重新登入，並更新仍使用舊名稱的服務、排程工作或遠端連線。此操作適用於本機帳戶。
