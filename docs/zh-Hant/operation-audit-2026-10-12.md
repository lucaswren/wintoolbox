# 功能、操作與介面審查 · 2026-10-12

## 原因及修正

舊版逐一處理五個高風險連接埠，每個都啟動 PowerShell 並複查；失敗再呼叫 netsh。移除操作在批次刪除後仍重複執行五次 netsh。只有個別命令逾時限制，沒有整體工作流程預算。此工作站的唯讀防火牆查詢約 2 秒，並非真實封鎖寫入的效能比較。

前端只停用按鈕，缺少執行階段和耗時，且在最後重新整理之前就通知成功。現已修正：

- 五個連接埠以一次 PowerShell 批次寫入，成功不再執行 netsh 修復。命令工作流程共享 60 秒預算，批次命令限時 30 秒。
- 驗證方向為輸入、TCP、啟用、封鎖、全部設定檔及目標連接埠。無法可靠讀取時保持未知；移除必須確認五個規則完全不存在，包括停用的規則。
- 已啟用的遠端桌面若使用預設封鎖清單中的連接埠，或讀不到設定，會中止封鎖，避免自訂連接埠遭中斷。
- 主捲動區域上方持續顯示執行、複查、完成、需要複查或未完成及耗時。切換頁面仍可見，結果保留到關閉或下一次操作。失敗後也讀取狀態，以呈現部分變更；不會自動回復 Windows 已接受的操作。
- 五個連接埠逐一顯示規則設定結果。規則存在不代表端到端封鎖有效；設定檔、網域原則、雲端控制及路由仍影響連線。
- 遠端桌面不再先改寫介面再複查；鎖定原則移除重複重新整理。帳戶啟用狀態增加回讀。
- Windows Update 狀態未知時不確認停用成功，標籤改為設定偵測結果。NTP 測試必須收到時間偏移樣本，內嵌 Windows 錯誤碼不能視為成功。

## 全模組結論

| 模組 | 審查及限制 |
|---|---|
| 本機概覽 | 快速與詳細收集、快取、啟用資訊、缺漏欄位及容量單位；逾時不捏造資料。 |
| 本機帳戶 | 密碼驗證、目前使用者保護、帳戶與管理員群組回讀、Guest、自動登入及原則。密碼 API 接受不等於完成登入測試；網域原則可覆寫。 |
| 遠端桌面 | 連接埠、規則同步／回復、NLA、服務重啟與記錄清理。設定不等於實際接聽或外部可達；內建規則群組同步仍為非同步。 |
| 防火牆 | 設定檔、允許、ICMP Echo、五埠預設及刪除。未知不當成成功，其他軟體的規則不移除；實際流量需另行驗證。 |
| 安全設定 | SMB 服務端、可選元件、WinRM、匿名列舉；可能需要重新啟動，不代表完整安全基準。 |
| Microsoft Defender | 偏好／原則、備份、防竄改失敗及回讀；啟用為強制開啟，不繞過防竄改保護。 |
| 時間同步 | 時區、來源、服務、重新同步及樣本；一次回應不代表長期可靠，命令不獨立量測時鐘精度。 |
| 電源 | 延遲、權限、強制關機／重新啟動、取消；排程成功不等於關機完成，鎖定會立即遮住介面。 |
| Windows Update | 有效備份、原則／服務／工作還原、損壞備份拒絕；原始設定停用時還原後仍可停用，系統或網域可再次變更。 |
| 軟體更新 | 發行資源、校驗、取消、暫存 ACL、替換與回復記錄；已有獨立下載進度。SHA256 不驗證發行者，程式存活不等於完整就緒，EXE 尚無簽章。 |

## 驗證與後續驗收

通過 15 項前端測試、lint／型別／格式、Go 測試及 vet、橋接一致性、PowerShell 語法解析、三種語言十個頁面與 Windows 正式建置。模擬瀏覽器暫停寫入和複查，驗證等待、成功、失敗及未知警告。涵蓋 960×600、1280×800 預設概覽、草稿、語言偏好與確認對話框。本機未執行封鎖、帳戶、防護、更新或電源寫入。

長訊息換行，超長結果可在有限區域內捲動。記錄仍僅存於目前工作階段；舊標註圖片不含新提示欄。文件已補充操作階段、部分變更及設定與實際效果的差異。

真實寫入需在一次性 Windows 虛擬機驗收：成功、服務停用、網域管理、存取拒絕、逾時、部分生效、重複／限縮規則、移除停用規則、自訂遠端桌面連接埠及全部防火牆設定檔關閉；從其他機器測試輸入連線。另需 UAC／WebView2、DPI、多螢幕、SMB 重啟及更新工作的測試。

60 秒預算僅適用於高風險連接埠命令工作流程；SMB 元件、Windows 更新服務／工作與原則傳播仍可能更久。不是所有原生呼叫都能取消，逾時不代表沒有變更，必須重新整理並檢查部分狀態。
