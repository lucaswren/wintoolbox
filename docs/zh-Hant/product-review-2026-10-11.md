# 軟體審查 · 2026-10-11

更新：現已採用 Apache-2.0，請見 [LICENSE](../../LICENSE) 與 [NOTICE](../../NOTICE)。下方授權建議保留先前審查紀錄。語言識別碼已改為不含地區的 en、zh-Hans、zh-Hant。

已檢查 Wails 視窗、十個功能頁面、多語言、帳戶、遠端桌面、防火牆、安全設定、狀態收集、原生啟動、自動更新、建置腳本及儲存庫資料。

預設視窗為 1280×800，最小為 960×600。概覽改為雙欄並縮短導覽列；三種語言的預設概覽與側欄均無溢位。小視窗、較長的裝置清單仍保留必要捲動。顯示名稱及新建置執行檔統一為 WinToolBox，既有防火牆規則名稱、更新快取與語言偏好保持相容。

支援英語、繁體中文與簡體中文。初次啟動辨識 Windows 顯示語言，其他語言使用英語；手動選擇會儲存。沒有獨立安裝程式，直接執行 EXE；缺少 WebView2 時提供對應語言的安裝提示。文件以英語為主，提供兩種中文版本，既有圖片仍為歷史簡體中文示意。

容量單位修正為 GiB，磁碟區顯示可用／總容量。防毒模組明確命名為 Microsoft Defender。NLA 在建立工作階段前驗證身分；密碼複雜度遵循 Windows 原則並影響後續密碼變更。安全功能提供個別設定，不代表完整安全評估；更新訊息描述是否發現較新版本。

資源鎖及操作後重新整理可減少操作重疊並呈現部分失敗。自動更新驗證 SHA256、重新檢查暫存檔案、限制暫存目錄權限並保留替換／回復記錄。校驗碼與發行資源共用信任邊界，不能取代發行者身分驗證。EXE 尚無 Authenticode 簽章，建議後續發行優先補充。

本機狀態不代表雲端安全群組或端到端連線能力；網域原則、Defender 防竄改保護及重新啟動條件應另外確認。

驗證通過：前端 lint、型別與格式檢查、11 項測試，Go 測試及 vet、橋接一致性、Windows 正式建置，以及三種語言十個頁面的模擬瀏覽器測試。包含 960×600 版面、切換、表單草稿、確認對話框、偏好儲存及 1280×800 無溢位斷言。測試不執行系統管理寫入。原生 UAC、全新系統 WebView2 安裝、多螢幕／DPI 與破壞性操作仍需隔離 Windows 虛擬機驗收。
