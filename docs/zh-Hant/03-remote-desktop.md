# 03 · 遠端桌面

管理 RDP 連線設定、來源 IP 白名單與伺服器登入記錄。

## 第一步：下載

https://github.com/lucaswren/wintoolbox/releases/latest

攔截點 **保留 / 保持**。詳：[00 · 下載](./00-download.md)

![下載攔截示意（模擬）](../images/00-download.png)

## 介面標注

![遠端桌面（真實介面）](../images/03-remote-desktop.png)

| # | 選項 | 說明 |
|---|------|------|
| ① | **連接埠** | 保護流程接受 1024–65535；更換連接埠不能替代來源限制 |
| ② | **保存連接埠** | 保存原設定、建立 SYSTEM 還原工作並新增受限 TCP/UDP 規則；約十秒後重啟 RDP 服務 |
| ③ | **開啟 / 關閉** | 開關遠端桌面服務（圖示為已開啟時的「關閉」） |
| ④ | **強制 NLA** | 認證前拒絕連線；極舊客戶端可能連不上 |

頁面依連線設定、**存取限制**、**登入記錄**排列。規則與原始輸出預設收合於 **診斷詳情**；登入記錄按需讀取並可展開詳細資料。**用戶端記錄**保留歷史主機、憑證、相關檔案與快取的搜尋、類型篩選、單筆刪除、分類清理及全部清理，開啟頁籤時讀取；舊截圖僅供位置參考。

## 步驟

1. **遠端桌面** → 填寫連接埠（①）→ **保存連接埠**（②）
2. 未開啟則點 **開啟**（③）→ **強制 NLA**（④）
3. 客戶端使用 `IP:新連接埠`；雲主機請同步安全組
4. 五分鐘內重新連線，再於頂部確認保留；未確認則由獨立工作還原，程式退出後仍有效。

新增來源 IP/CIDR 白名單、TermService 真實監聽檢查、有效策略規則列表，以及伺服器登入與斷線事件。NLA 和啟用全部防火牆也使用保護流程；既有連線不能確認保留。網域控制站、未知會話或受管 RDP 策略會保守拒絕修改。

請先保留 VPS 控制臺通道。本機還原無法修復雲端安全組、NAT 或系統故障；仍需在各 Windows Server Desktop Experience 版本實機驗收。完整流程、限制與復原方式見[簡體中文保護指南](../zh-Hans/03-remote-desktop.md#vps-防失联保护)。

- 狀態異常時先點右上角 **刷新**
