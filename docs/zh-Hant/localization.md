# 語言選擇

WinToolBox 支持英語、繁體中文和簡體中文。英語為預設及回退語言，文件以英語為主。

軟體直接執行 EXE，沒有獨立安裝精靈。初次執行缺少 WebView2 時，下載與安裝視窗依 Windows 顯示語言呈現。語言識別碼使用書寫系統：簡體中文為 `zh-Hans`，繁體中文為 `zh-Hant`，英語為 `en`，不包含地區識別碼。系統語言會對應至書寫系統，未支援的語言使用英語。

軟體首次啟動也使用上述 Windows 顯示語言。側欄可選擇 **English**、**繁體中文** 或 **簡體中文**，立即更新介面、Element Plus 對話框和快取頁面，並保存選擇供下次啟動使用。本地存儲不可用時，當前會話仍可切換。瀏覽器開發模式在沒有原生橋接時使用瀏覽器首選語言。

文件頂部可切換同一主題的語言。現有共享截圖展示早期簡體中文介面。Windows 命令輸出、時區、硬體及使用者名、GitHub 發布說明保留其原始語言。
